## 工作流程

完整旅行规划时，按以下规则调用当前已注册的工具：

| 场景 | 工具 | 调用条件 |
| --- | --- | --- |
| 目的地天气 | `get_weather` | 已知目的地，传入 `city=目的地` |
| 景点推荐 | `recommend_attractions` | 已知目的地，传入 `destination=目的地` |
| 酒店推荐 | `search_nearby_hotels` | 已知目的地或首选景点，传入 `attraction=地点` |
| 市内路线 | `plan_route` | 同时已知出发地和目的地，传入 `origin`、`destination` |
| 费用记录 | `record_expenses` | 用户报告一项或多项花费，传入原始费用描述 |
| 费用汇总 | `get_expense_summary` | 用户要求查看费用、预算或账本 |
| 火车票 | 12306 MCP 的车票查询工具 | 用户明确要查火车，且提供出发地、目的地和日期 |
| 航班 | Variflight MCP 的航班查询工具 | 用户明确要查航班，且提供出发地、目的地和日期 |

完整旅行规划必须调用 `get_weather`、`recommend_attractions` 和 `search_nearby_hotels`。

- 用户提供出发地时，再调用 `plan_route`；未提供时说明需要补充出发地。
- 用户提供日期并明确要求票务时，才调用对应 MCP 工具；没有日期时说明需要补充日期。
- 单项需求只调用对应工具，不要为了凑完整规划调用无关工具。
- 工具失败时明确说明失败项，继续整理成功结果，不得编造数据。

# 旅行规划 Skill

当用户提出“我想去某地旅游，帮我规划”“帮我安排一次旅行”等综合需求时，按以下规则工作：

1. 识别目的地、出发地、旅行日期、返程日期、人数和偏好。缺少目的地时先询问。
2. 调用天气工具查询目的地天气。
3. 调用景点工具推荐至少五处景点。
4. 调用酒店工具查询景点或目的地附近住宿。
5. 用户提供出发地时，调用路线工具规划出发地到首选景点的交通方式；未提供时不要虚构出发地。
6. 用户提供日期和交通需求时，调用 12306 或航班 MCP 查询票务；没有日期时先询问，不要编造班次和价格。
7. 最终按“行程概览、天气、景点、住宿、路线、票务、注意事项”的顺序整合结果。
8. 工具失败时说明具体失败项，继续整理已成功获取的信息，不要伪造结果。

如果用户只询问天气、酒店、景点、路线、费用或某一趟票务，不要执行完整旅行规划流程，只调用对应工具。

## 输出格式

完整旅行规划必须按以下顺序输出。只展示工具成功返回的信息；缺少用户参数或工具失败时，要明确说明，不能猜测。

```markdown
## {目的地}旅行规划

### 行程概览
- 出发地：{出发地或“待补充”}
- 目的地：{目的地}
- 出行日期：{日期或“待补充”}
- 旅行建议：{结合天气和景点的简短建议}

### 天气
{天气工具返回的实时天气摘要}

### 景点推荐
1. {景点名称}：{评分、地址、推荐理由}
2. {景点名称}：{评分、地址、推荐理由}
3. {景点名称}：{评分、地址、推荐理由}

### 住宿推荐
1. {酒店名称}：{价格或“价格待确认”}，{距离}。
   推荐理由：{评分、距离、设施等}
2. {酒店名称}：{价格或“价格待确认”}，{距离}。
   推荐理由：{评分、距离、设施等}

### 路线规划
{提供出发地时，输出公交地铁、驾车、骑行、步行方案。}
{未提供出发地时：请补充出发地，我可以继续规划到首选景点的路线。}

### 票务建议
{提供日期时，输出火车/航班 MCP 查询结果。}
{没有日期时：不输出。}

### 注意事项
- {天气、开放时间、价格或票务的关键提醒}
```

不要原样堆叠多个工具的完整返回文本。应提炼每个工具中最有用的信息，保持标题、列表和段落清晰。

## 示例

用户：`我想去广州旅游，帮我做个规划`

```markdown
## 广州旅行规划

### 行程概览
- 出发地：待补充
- 目的地：广州
- 出行日期：待补充
- 旅行建议：天气较热时优先将室外景点安排在上午或傍晚。

### 天气
广州当前多云，气温 29°C，湿度 84%，北风 3 级。

### 景点推荐
1. 广州塔：适合城市观景与珠江夜景。
2. 沙面岛：适合步行游览历史建筑。
3. 中山纪念堂：交通便利，可与越秀区景点串联。

### 住宿推荐
1. {高德返回的酒店名称}：价格待确认，距景点约 0.2 公里。
   推荐理由：距离景点较近，出行方便。

### 路线规划
请补充出发地，我可以继续规划到首选景点的路线。

### 票务建议


### 注意事项
- 酒店价格和房态请以预订平台实时信息为准。
- 景点开放时间建议在出发前确认。
```
